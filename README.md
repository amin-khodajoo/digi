# پروژه وب‌سایت دیجی‌کالا (شبیه‌سازی)

من یک وب‌سایت شبیه‌سازی شده از **دیجی‌کالا** طراحی کرده‌ام که شامل ۳ صفحه اصلی زیر است:  
- صفحه اصلی  
- صفحه شگفت‌انگیزها  
- صفحه ورود | ثبت‌نام  

این پروژه با استفاده از **HTML** و **CSS** پیاده‌سازی شده است و برای ایجاد اسلایدرهای تعاملی از کتابخانه‌ی **Swiper** بهره برده‌ام.
