# پروژه طراحی صفحات سایت دیجی‌کالا

در این پروژه، من سه صفحه از سایت **دیجی‌کالا** را با استفاده از **HTML** و **CSS** طراحی کرده‌ام.  
صفحات طراحی شده عبارت‌اند از:  
- صفحه اصلی  
- صفحه شگفت‌انگیزها  
- صفحه ورود و ثبت‌نام  

برای ایجاد اسلایدرهای تعاملی و روان در این پروژه از **Swiper Slider** استفاده شده است.  

این پروژه به من کمک کرد تا مهارت‌های طراحی صفحات وب استاندارد و واکنش‌گرا را تقویت کنم.
